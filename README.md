# Gonvy

> **Gonvy** is an end-to-end environment variable and secret management platform built for modern development teams, cloud environments, and automated pipelines.

---

## 🎯 Vision & Purpose

Managing environment variables and sensitive configuration across developers, environments (development, staging, production), and CI/CD pipelines is often fragmented, manual, and prone to security leaks.

**Gonvy** provides a single source of truth for your application secrets:
- **Centralized Management:** Synchronize environment variables across your team and deployment targets seamlessly.
- **Role-Based Access Control (RBAC):** Restrict sensitive credentials based on developer roles and environments.
- **Audit Logging & History:** Track exact secret changes, revisions, and access events over time.
- **Developer-First Experience:** Native integration into local workflows via CLI and real-time dashboard UI.

---

## 🔮 Creative Highlight: Contextual Drift Detection

Beyond static key-value management, Gonvy introduces **Contextual Drift Detection**. Gonvy continuously monitors your active development `.env` files, staging setups, and production secret stores to flag schema mismatches, missing keys, or unexpected type mutations before they hit runtime.

## 📁 Repository Structure

Gonvy is structured as a high-performance **Turborepo** monorepo managed with **pnpm**:

```
gonvy/
├── apps/
│   ├── api/          # Core backend REST API (Go, Gin, GORM, PostgreSQL)
│   └── www/          # Web dashboard application (Next.js 16, React 19, Sass)
└── packages/

    ├── biome/        # Shared code style and linting configuration

    └── vitest/       # Shared Vitest testing suite setups
```

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v20+ recommended)
- [pnpm](https://pnpm.io/) (v11+)
- [Go](https://go.dev/) (v1.26+)
- [PostgreSQL](https://www.postgresql.org/) (or Docker)

### Installation & Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/0xlebogang/gonvy.git
   cd gonvy
   ```

2. **Install dependencies:**
   ```bash
   pnpm install
   ```

3. **Start the development servers:**
   ```bash
   pnpm dev
   ```
   *Runs Turborepo across all apps (`www` and `api`).*
